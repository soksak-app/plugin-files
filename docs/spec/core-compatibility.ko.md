# Core 호환성

[English](core-compatibility.md)

Files package는 `engines.soksak: "^0.0.34"`를 선언한다. 이 범위는 core version-range 규칙에 따라 core release `0.0.34`를 허용하고
이전 version 및 검증하지 않은 이후 version을 제외한다. Core `0.0.34`는 이 package의 `plugin.json`을 받으며, 그 `sections`는 core
`docs/spec/plugins.md#sections`의 section view 형태, 즉 `composition`과 `height`를 가진다.
